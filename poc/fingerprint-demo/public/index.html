Timing and technical details

The short version

An AI image leaves traces at three depths: file metadata, pixel-level patterns, and mid-level "rendering style". Laundering (JPEG plus resizing) erases them from the bottom up. Only the style survives, if the probe was trained on laundered copies. Every figure below is parsed from a result file and cites it.

Phone fingerprints (PRNU)

Every camera sensor has tiny fixed differences between pixels. Average the noise of a phone's photos into a reference pattern and you can ask: does this new photo correlate with it? The score is PCE (peak-to-correlation energy); 60 is the usual "match" line.

Each cell: the photo came from the row device (y), compared with the column device's reference (x). Colour is the median PCE on a log scale. A bright diagonal means "the right phone wins".
