# 015-midlayer-probe (E6, Amendment 15) - design and results

Exploratory (D-016). Run: `env/.venv/bin/python -I experiments/015-midlayer-probe/run.py all --workers 8` (stages `fit`, `eval`; resumable via `cache/`, ~3 min on CPU). Self-test: `selftest.py` (output `results/selftest.txt`, all PASS). No GPU, no new feature extraction: everything uses the cached 004 DINOv2-base features (`feats` = orig, `fov512`), all five conditions (clean, jpeg75_resize05, social_sim, screenshot_sim, mavali_medium) exist for both arms and for all 2,919 rows. Constants frozen in `config.json` before any result. Every number below is in `results/results.json` / `results/tables.md`.

## Design (as pre-registered; interpretations marked I)
- Features: F_b8 = columns 1536:3072 of the 4608-d secondary matrix (layout `[b4 CLS|b4 mean|b8 CLS|b8 mean|b12 CLS|b12 mean]`, verified in `selftest.py`: B0 primary == last 1536 columns); F_last = 3072:4608 (= B0 primary); F_cat = all 4608.
- Probe: `lib/probe.fit_probe`, balanced, `StratifiedGroupKFold` over C. Groups: device (VISION), caption id (a RAISE real and ALL its fakes, every generator incl. FLUX), image otherwise; augmented copies share their source group. Regimes T-clean (clean) and T-aug (clean + jpeg75_resize05 + social_sim copies of every train image). screenshot_sim and mavali_medium are never used for fitting.
- Train rows follow the 005 A0 / 003 recipe: VISION natives + RAISE reals + fakes of the 7 train generators (WA/FBH copies are not train rows). LOGO over the 7 generators; FLUX scored by the `full` model.
- I - Twin-disjoint splits. The official splits are not twin-consistent: only 120 of the 435 train fakes survive if every train row sharing a caption id with a calib/test row is dropped. So caption families (all rows with one `r<hex>t` id) are placed whole on the TRAIN side or the EVAL side (calib/test; these may share ids since neither trains) by the majority of their official rows (ties -> eval); rows of the other side are dropped from E6. Kept rows keep their official split; no caption id is in both train and calib/test (checked). Result (orig = fov512): train 99 natives + 84 RAISE reals + 230 fakes (dalle2 37, dalle3 20, firefly 30, mj 22, sd3 41, sd2 41, sdxl 39); test 358 natives (+358 WA, 358 FBH), 183 RAISE reals, fakes 55/58/57/55/54/60/62 and FLUX 131 (19 of 150 FLUX dropped); calib 129 VISION + 53 RAISE reals. 258 fakes and 79 RAISE reals dropped.
- I - Primary real set for AUROC = test VISION natives + RAISE test reals (the 003 convention; WA/FBH are per-pool rows). LOGO-macro = mean over the 7 train generators + FLUX (8 values); macro over the 7 is a sensitivity table.
- I - B0 comparator for P1: (a) "matched" = F_last, T-clean, same rows/groups/balanced/CV as F_b8 (only the features differ); (b) "003-literal" = `fit_probe` on `b0_train` clean last-block features, no groups, unweighted (its train rows include twins of the E6 test rows, so it is the less strict comparator). P1 is PASS only if it passes against both; both give the same label.
- Cross-source: `raise_only` (train reals = RAISE only) scored against test natives+WA+FBH; `vision_only` (natives only) against RAISE test reals; same fakes protocol (LOGO macro over 8).
- Twin-paired AUROC: RAISE test reals vs their test caption-twin fakes (144 ids, 238 pairs: 27/27/31/27/10/20/32 + FLUX 64), per-generator AUROC under that generator's LOGO model (FLUX: full), pairs-weighted mean; CI = bootstrap over caption ids. Matched-pair win rate also reported.
- FPR: threshold = 1% FPR on the pooled calib reals' clean scores of the same model (model `full`), applied to every pool and condition; Clopper-Pearson 95% CIs.
- Bootstrap: 1,000 replicates, reals by device (RAISE per image), fakes by image within generator (`lib/metrics.bootstrap_weights`), one plan shared by all methods (paired differences). The macro CIs do not resample twin families jointly (only the twin-paired CIs do).
- Texture: `lap224` (mean |4-neighbour Laplacian| of the gray 224 center crop of the conditioned image, as 009) computed on the arm's images; sign from calib reals vs train fakes; the gate uses the better of both signs.
- Fragility: P1/P2 labels recomputed with each generator (and Firefly) dropped from the macro (as `005/gate_robustness.py`; the FLUX criterion is unchanged).

## Results (arm orig = label arm; jpeg75_resize05 unless stated; LOGO-macro AUROC over 8 generators, primary reals, 95% CI)
**P1 (improvement over B0): PASS** (also vs both B0 comparators, and robust to dropping any generator).
- F_b8 T-aug 0.947 [0.933, 0.960] vs B0-matched 0.855 [0.822, 0.881]: gain +0.092 [+0.069, +0.121]; vs B0-003-literal 0.864 [0.831, 0.889]: +0.083 [+0.059, +0.114].
- FLUX: F_b8 T-aug 0.874 [0.839, 0.908] vs 0.797 / 0.816: +0.077 [+0.030, +0.124] / +0.059 [+0.013, +0.106].
- Clean: F_b8 T-aug 0.970 vs B0 0.904 / 0.917 -> no loss (loss -0.066 / -0.053). Macro over 7 generators: gain +0.095 (CI lower bound +0.071). 
- Held-out launderings, F_b8 T-aug vs B0-matched / 003-literal: screenshot_sim 0.961 vs 0.890 / 0.902 (+0.071 [+0.052, +0.093] / +0.060 [+0.041, +0.084]); mavali_medium 0.942 vs 0.869 / 0.884. social_sim 0.963 vs 0.895 / 0.909.

**T-clean vs T-aug (LOGO-macro / FLUX, orig):** F_b8 clean-trained 0.901 / 0.777 at jpeg75_resize05 (0.973 / 0.963 clean) vs laundering-augmented 0.947 / 0.874 (0.970 / 0.951 clean); F_cat 0.921 / 0.881 vs 0.945 / 0.908 (clean 0.963 / 0.981 vs 0.965 / 0.956); F_last 0.855 / 0.797 vs 0.883 / 0.848 (clean 0.904 / 0.868 vs 0.909 / 0.883). So the layer alone gives +0.046 [+0.020, +0.076] macro over matched B0 but NOT on FLUX (-0.020 [-0.073, +0.034]); the FLUX gain and about half of the macro gain need laundered training. Augmentation alone on the last block gives only +0.028 macro / +0.050 FLUX over matched B0 (it leaves the 003-literal B0 within CI on social_sim).

**P2 (falsifier): FAIL, residual is "real-source-specific".**
- Twin-paired laundered AUROC (F_b8 T-aug): 0.889 [0.858, 0.916], win rate 0.90 (>= 0.85 holds; per generator 0.79 FLUX ... 1.00 dalle3; SD2 has only 10 pairs). B0-matched 0.701, B0-003-literal 0.756.
- Cross-source laundered AUROC: RAISE-only -> VISION reals 0.644 [0.597, 0.691]; VISION-only -> RAISE reals 0.604 [0.558, 0.650] (both < 0.85; clean 0.534 / 0.497; T-clean at jpeg75_resize05 0.511 / 0.529; below chance clean for RAISE-only, 0.323). Same drop for F_cat (0.609 / 0.614) and F_last (0.665 / 0.615).
- Pipeline control (not pre-registered, from the same fits): in-source AUROC is high (RAISE-only -> RAISE 0.916, VISION-only -> native 0.998 at jpeg75_resize05), so the cross-source failure is a transfer failure, not a broken fit. The VISION-only -> native 0.998 also shows how easy the VISION-vs-fakes format/content cue is.
- Drop-one: P2 fails in all 11 subsets (cross-source 0.58-0.68).

**P3 (FPR at the pooled 1% calib threshold, F_b8 T-aug `full` model, jpeg75_resize05): FAIL.** native 0.8% (3/358) [0.2, 2.4], WA 3.1% (11/358) [1.5, 5.4], FBH 2.2% (8/358) [1.0, 4.4], RAISE 7.1% (13/183) [3.8, 11.8]; clean RAISE 6.6%. Only native meets <= 2%. (B0-matched F_last T-clean: 0.3-0.8% on VISION pools, RAISE 1.1%, i.e. a conservative detector with TPR@1%FPR 0.15 vs F_b8 T-aug 0.57; F_b8 T-clean at jpeg75_resize05: 2.8-9.8%.) Caveat: the calib VISION devices are also train devices (official split), so the calibrated threshold is optimistic for VISION reals.

**Gates.** Laplacian texture baseline laundered (jpeg75_resize05): 0.635 [0.575, 0.684] (< 0.70, best sign = chosen sign; clean 0.712 [0.665, 0.753] is above 0.70 but only the laundered value is gated) -> PASS. Label fragility: no label flips when any generator, FLUX or Firefly is dropped (P1 vs both B0 comparators PASS in all 11 subsets, gain lower bound >= +0.056; P2 FAIL in all) -> not fragile. F_b8 T-clean reported above.

**Arm fov512 (descriptive; same code).** F_b8 T-aug jpeg75_resize05 0.953 [0.939, 0.966] vs matched B0 0.884 / 003-literal 0.885: gain +0.070 [+0.049, +0.097] / +0.068 [+0.046, +0.100]; FLUX 0.913 vs 0.840 / 0.858 (+0.073 [+0.036, +0.118]); P1 PASS. Twin-paired 0.906 [0.880, 0.929] (B0 003-literal 0.788). ## Caveats
- One real photo pipeline per real source: the cross-source test is the only evidence about transfer and it fails; P1's gain is measured against reals that contain the training sources (VISION natives + RAISE), so it supports "better on these two real pipelines", not generalization to a new real pipeline.
- Smaller training set than 003 (230 vs 435 fakes) because of the twin-disjoint rule; C hit the grid edge (0.01 or 10) in several fits.
- Few twin pairs for SD2 (10) and SDXL (20); FLUX test n = 131 after twin pruning.
- WA/FBH are copies of the natives, so pool rows and "vision3" are not independent samples (clustered by device in the CIs).
