# 017-embedding-geometry (E8, Amendment 17) - embedding geometry and a source-invariant diffusion direction

Exploratory (D-016). CPU only, no downloads, no new GPU features (D-008 not triggered; features are the E7/004 caches). Readings and thresholds exactly as pre-registered. Constants in `config.json`.
Run: `env/.venv/bin/python -I experiments/017-embedding-geometry/run.py all --workers 14` (stages m1, m2fit, m3u, m3fit, analyze, map, report; resumable via `cache/`). Self-test: `selftest.py` (synthetic + real-data plumbing, `results/selftest.txt`, ALL PASS). ## Design (Amendment 17 as implemented; interpretations marked I)
- Data: E7's splits, E6 caption-family roles and groups, 004/E7 cached features; block 8 = columns 1536:3072, B0 = 3072:4608, blocks 4/8/12 = all 4608. Arms fov512 (primary) and orig. Conditions clean and jpeg75_resize05; T-aug (clean, jpeg75_resize05, social_sim) for training as in E7. Bootstrap: 1,000 cluster replicates (E7 `Plan` for held-out evaluation; one global group plan for C2ST).
- **M1.** C2ST = logistic probe (E7 recipe, balanced, grouped inner CV) in a 5-fold StratifiedGroupKFold (groups device / caption family / image, so twins are held out together); pooled out-of-fold AUROC, mean of 3 CV seeds (block 8; 1 seed for last layer and blocks 4/8/12). Source rows: VISION natives, RAISE, OI (all roles); fake rows: all 1,020 fakes (8 generators, all roles). I: all roles are used (C2ST needs no train/test roles); a size-matched variant (399 rows per class, 3 subsamples) is reported next to the full-data headline. Ratio = mean of the 3 real-real AUROCs / mean of the 3 real-vs-fake AUROCs (per bootstrap replicate).
- **M2.** d_twin = mean over (train fake, its RAISE train real of the same caption id) pairs of x_fake - x_real (99 pairs, 71 reals, 71 families, fov512). I: headline = mean over the three T-aug conditions of the pair differences; the clean-only and jpeg75_resize05-only versions are reported (cosine to the T-aug one 0.93-0.95). d_probe(S) = raw-space normal of an E7-recipe T-aug probe, S's train reals vs the 7 train generators, re-expressed in a common standardized space (pooled train rows of all three sources; raw-space cosines are the sensitivity). The d_twin projection AUROC uses a twin-only scaler (RAISE train rows), so no held-out source information enters. LOGO: for generator g the direction is re-estimated without g's pairs; FPR uses the full direction and the 1% threshold of RAISE calib reals (reading A = clean calib scores, B = same condition; A is the E7 headline). Held-out sources: VISION (natives + WA + FBH, as E7) and OI; RAISE is shown as an in-source reference. A split-half noise reference for probe-normal cosines is added (two random half-group refits at the full-fit C).
- **M3.** Source-nuisance subspace estimated from the training sources' train reals only (T-aug stack, scaler from those reals; independent of any fake). I (the one design choice that was not unique): the Amendment's "k <= number of training sources - 1 + 8" cannot be met by mean differences alone with 2 training sources, so the columns are, in order: (1) the n-1 shrinkage-LDA directions; (2) the n-1 between-source mean-difference directions (the rank n-1 PCA of the source means; added because Sigma^-1 dmu is not dmu when within-source covariance is anisotropic, and a synthetic check showed LDA alone leaves most of the shift); (3) the top j = 0, 1, 2, 4, 8 principal directions of the source-balanced matrix of cluster means (cluster = device / caption family / image). Removed dimensions k = 2(n-1) + j = 2, 3, 4, 6, 10, so the PCA part (1 + j directions) respects the bound n-1+8 = 9. Project out, retrain the E7 probe (same rows, balanced, grouped CV, LOGO per generator), evaluate on S with the E7 `eval` logic (same Plan, same FPR readings).
  - k selection (calib data of the TRAINING sources only; I): there are no calib-role fakes in the E6 roles, so the criterion uses calib reals only: the AUROC of a source classifier retrained on the projected training reals and scored on the training sources' calib reals (VISION: natives); k = the smallest value within 0.02 of the minimum over the grid. All k are reported, so the verdict does not depend on this rule (uniform-j table).
  - Labels: PASS-R3 if every held-out source has AUROC >= 0.85 and FPR <= 5%; KILL if no held-out source improves over E7 by >= 0.03 AUROC or >= 5 points of FPR; else INCONCLUSIVE (point estimates, CIs shown). Drop-one-generator: macro without g, FPR from the LOGO model that never saw g, as E7. Sensitivity excluding the content-confounded RAISE fold is in results.json.
- **Texture baseline:** E6's Laplacian statistic, sign chosen on training-source calib reals vs train fakes.
- **M4:** PCA of standardized block-8 features (fit on clean and laundered jointly) and t-SNE (50 PCs, perplexity 30, 1,800 random points), descriptive.

## Results (fov512, jpeg75_resize05, block 8 unless stated; source: results/tables.md)
- **M1 (R1 holds, but uninformative at ceiling).** Mean real-real C2ST 0.977 [0.967, 0.985] vs mean real-vs-fake 0.984 [0.979, 0.987]; ratio **0.994 [0.985, 1.001]** (>= 0.9, so "entangled"). Size-matched ratio 0.994. Pairs: VISION-RAISE 0.986, VISION-OI 0.967, RAISE-OI 0.979 vs VISION-fake 0.995, RAISE-fake 0.977, OI-fake 0.979. Clean 0.995; last layer 1.004; blocks 4/8/12 0.992; orig 1.005. All C2ST values are near 0.98, so the ratio cannot separate the two, and the real-vs-fake pairs for VISION and OI include content differences (only RAISE is twin-matched: 0.977). Descriptively, source identity among reals accounts for 30% of PC1 variance (eta^2) in the 2-D map (`results/part_map_fov512.json`).
- **M2 (R2 fails).** Cosines between d_probe(S): VISION-RAISE 0.351, VISION-OI 0.385, RAISE-OI 0.294 (min 0.294 < 0.5; the split-half noise references for the same probe are 0.34 / 0.50 / 0.39, so these are at the noise ceiling and the pairs are only weakly aligned at best). d_twin cosines: RAISE 0.643, VISION 0.234, OI 0.176. d_twin alone: AUROC VISION **0.802 [0.755, 0.846]** (FPR 0.9%, 10/1074), OI **0.554 [0.507, 0.597]** (FPR 15.0%, 30/200); RAISE in-source 0.832. R2 needs both >= 0.80 and min cos >= 0.5: **not met** in any of the 10 drop-one subsets (min cos 0.29-0.34, OI AUROC 0.52-0.58). The twin direction transfers to the VISION phone photos but not to the OI Flickr photos. Last layer is worse (VISION 0.684, OI 0.521). orig arm: VISION 0.495, OI 0.397.
- **M3 (R3 not met; KILL on the primary arm).** Chosen k and change vs E7 (AUROC / FPR, reading A): VISION k=4 0.898 / 0.7% (E7 0.917 / 0.6%); RAISE k=3 0.687 / 18.6% (0.689 / 19.1%); OI k=2 0.797 / 17.5% (0.809 / 16.0%). No source improves by >= 0.03 AUROC or >= 5 FPR points, and the AUROC changes are -0.019, -0.003, -0.011 (paired CIs exclude 0 for VISION and OI, so removal slightly hurts). Label **KILL** under readings A and B, in all 10 drop-one subsets, for every uniform j (0, 1, 2, 4, 8), and excluding RAISE. Removal does what it is built to do on its own target (calib source-ID AUROC 0.97 -> 0.47-0.52 at k=2-4) without helping detection of the held-out source.
- **orig arm (reported).** M1 ratio 1.005 (R1 holds); R2 fails (min cos 0.18, d_twin AUROC VISION 0.495, OI 0.397); M3 chosen k: VISION 0.814 / 4.1% (E7 0.851 / 2.3%), RAISE 0.623 / 35.5%, OI 0.741 / 22.0% (E7 0.753 / 35.0%). The literal rule gives **INCONCLUSIVE** under reading A (OI FPR falls 13 points at a 0.012 AUROC loss, and the three sources still sit at AUROC 0.62-0.81 / FPR 4-36%) and KILL under reading B and in 5 of 10 drop-one subsets under A. It is the non-primary arm, and no source gets near the R3 bar.
- **Texture baseline:** laundered AUROC VISION 0.646, RAISE 0.502, OI 0.658 (< 0.70 gate holds; OI clean 0.725).
- Drop-one-generator: R2 and R3 verdicts unchanged in all 10 subsets (fov512).

## Deviations / interpretations to review
1. Source subspace definition (M3, item I above). The first implementation had only LDA + cluster-mean PCs; a synthetic check showed LDA alone does not remove an anisotropic mean shift, and the mean-difference directions were added BEFORE any held-out M3 result was inspected (only the calib source-ID diagnostics and the synthetic test had been seen; the first M3 held-out tables were generated but never opened).
2. k selection uses calib reals only (no calib fakes exist in the E6 roles).
3. d_twin and probe directions compared in a pooled-standardized space; the cosine between d_twin (a mean difference) and a probe normal (a regularized Sigma^-1 mean difference) is not expected to be 1 even for a shared effect; R2 itself only uses the probe-probe cosines and the d_twin AUROC.
4. C2ST uses all roles and VISION natives only; fakes include FLUX and the RAISE twins of RAISE reals.
5. Bootstrap CIs on probe cosines are not computed (the split-half reference is given instead).

## Caveats
- Three real sources; all fakes carry RAISE content, so the RAISE fold is content-confounded (E7 critique) and the VISION/OI C2ST real-vs-fake pairs contain content shift. R1 as defined cannot discriminate at AUROC ~0.98.
- The OI test set has 200 reals (FPR resolution 0.5%). No owner photos (still pending), so this does not feed the acceptance test.
